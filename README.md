# biom5350-git-intro

Starter repository for the BIOM5350 git/GitHub in-class activity.

## Contents

| File | Purpose |
|---|---|
| `gc_content.py` | Prints the GC content of every sequence in a FASTA file |
| `example.fasta` | Four short made-up sequences to test on |

## Usage

```bash
python gc_content.py example.fasta
```

Expected output:

```
seq1_AT_rich    GC = 0.0%
seq2_balanced   GC = 48.8%
seq3_GC_rich    GC = 100.0%
seq4_with_N     GC = 50.0%
```

## What to do with this

You will clone this repo in class, run the script, and then copy it into a
repository of your own and extend it. See the in-class notebook for the steps.
